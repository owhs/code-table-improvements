# A(18,4) >= 6144 and A(17,4) = A(16,3) >= 3072

| cell | table lower bound (2026-10-16) | new | table upper bound |
|---|---:|---:|---:|
| A(18,4) = A(17,3) | 5632 (Laaksonen, Ostergard 2016) | 6144 | 6551 |
| A(17,4) = A(16,3) | 2816 (Milshtein 2015) | 3072 | 3276 |

Table: https://aeb.win.tue.nl/codes/binary-1.html

## Files

- `A18_4_6144.txt`: the (18, 6144, 4) code, one word per line.
- `A17_4_3072.txt`: the (17, 3072, 4) code, the words of the first code with last coordinate 1, that coordinate deleted.
- `A16_3_3072.txt`: the (16, 3072, 3) code, the previous code punctured on its last coordinate.
- `check_binary.py`: standard-library check of lengths, duplicates and all pairwise distances.
- `z4_construction.json`: the construction (below).

```
python check_binary.py A18_4_6144.txt 4
python check_binary.py A17_4_3072.txt 4
python check_binary.py A16_3_3072.txt 3
```

## Construction

The length-18 code is the Gray image (0 -> 00, 1 -> 01, 2 -> 11, 3 -> 10; Z4 coordinate i gives binary positions 2i and 2i+1) of a
code C of length 9 over Z4 with minimum Lee distance 4. C is a union of 96 cosets of the Z4-submodule K generated by the six rows in
`z4_construction.json` (|K| = 64, all entries in {0, 2}); the file also lists one representative per coset, and C = representatives + K
rebuilds `A18_4_6144.txt` exactly. The cosets were chosen by a local search for a maximum independent set in the Cayley graph on
Z4^9 / K whose edges join cosets containing a difference of Lee weight 1 to 3. The Gray map is an isometry from Lee distance to
Hamming distance.

## Checks

Three separate programs: the search program's own pairwise check, a numpy bitwise all-pairs check, and the plain-Python script above.
Independently re-checked on 2026-10-16 with a separate all-pairs XOR check (minimum distances 4, 4, 3; no duplicates), and the Z4
structure was confirmed from the code file (closed under K, 96 cosets, minimum Lee distance 4).

## Literature checked

The 5632 bound is from A. Laaksonen and P. R. J. Ostergard, Constructing error-correcting binary codes using transitive permutation
groups (arXiv:1604.06022). The 2816 bound for A(16,3) is from M. Milshtein, A new binary code of length 16 and minimum distance 3,
Inform. Process. Lett. (2015), improving Romanov's 2720 (1983). Web searches for larger values of A(16,3), A(17,3), A(17,4) and A(18,4),
including Z4-linear constructions, found none. Not checked: full texts behind paywalls.
