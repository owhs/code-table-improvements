Bounds for spectral-signature codes

A word x of length n and weight w has the power signature Px(k) = |∑j xj exp(-2πijk/n)|2, k = 1,...,⌊n/2⌋ (the same information as the cyclic autocorrelation of the support, that is, the multiset of cyclic differences). Cyclic shifts, reflections and homometric words have the same signature. For w = n/2 a word and its complement have the same signature. Put d(x,y) = ∑k |Px(k) - Py(k)| / w2. A spectral code C(n,w,θ) is a set of binary words of length n and weight w with d(x,y) ≥ θ for all x ≠ y. S(n,w,θ) is the maximum size of such a code. The tables below give lower (and upper) bounds for this function for small parameters. A lower bound is demonstrated by giving an explicit code. Contact: GitHub user owhs.

Sources

The bounds on S(n,w,θ) were computed here; no earlier table of them was found. The numbers of signatures c(n,w) for n ≤ 24 can also be derived from the enumeration of Z-related (homometric) sets by F. Jedrzejewski & T. Johnson, The structure of Z-related sets, arXiv:1304.6608 (2013), together with the number of bracelets; our values agree in the cells checked. Lower bounds are explicit codes (the file is linked from the table, one word per line as a 0/1 matrix); an entry a-b means a ≤ S ≤ b, and a single number is exact (proved by integer programming). 239 of the 252 entries are exact; 13 are open. — means not computed (n = 20, w = 9: 3651 signatures, above the 3500 limit used).

The ordinary constant weight codes A(n,d,w) are tabulated in

BSSS: A. E. Brouwer, J. B. Shearer, N. J. A. Sloane & W. D. Smith,
A new table of constant weight codes,
IEEE Trans. Inform. Theory 36 (1990) 1334-1380.
There shifts of a word are different words and the distance is the Hamming distance; here two shifts of the same word cannot both be in a code. The 13 shifts of the (13,4,1) difference set {0,1,3,9} give A(13,6,4) = 13 but a single signature, so S = 1 for that family. Recovery of one binary signal from its Fourier magnitude is treated in
W. H. Wong, Y. Lou, S. Marchesini & T. Zeng,
One-dimensional phase retrieval: regularization, box relaxation and uniqueness,
arXiv:1904.10157.
and homometric sets in
A. Rosenblatt & P. D. Seymour,
The structure of homometric sets,
SIAM J. Algebraic Discrete Methods 3 (1982) 343-350.

For n = 16, w = 6, 12 words and Gaussian noise 0.2 on the 0/1 positions, a code of maximal minimum spectral distance has symbol error rate 0.009, against 0.117 for greedy Hamming codes of the same size (for n = 18, w = 6, 16 words: 0.006 against 0.113). At noise 0.5 the gain is small (0.474 against 0.666 for n = 16). The distance used is the L1 distance between noise-free signatures. No theorem is claimed; the literature was searched but not read in full (related_work.md).

The number of signatures c(n,w)

S(n,w,θ) ≤ c(n,w), with equality if and only if θ is at most the smallest distance between two classes. Since c(n,w) = c(n,n-w) only w ≤ n/2 is shown. For w ≤ 3 the number equals the number of bracelets; the first difference is w = 4, n = 8, where {0,1,2,5} and {0,1,3,4} have the same signature.
